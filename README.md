# 🤖 AI Text Generator

A beginner-friendly Generative AI application that generates text based on a user-provided topic.

## 🚀 Features

- Generate text from a topic
- Short, medium, and detailed output options
- Uses a pretrained Generative AI model
- Simple Streamlit interface
- No external API key required

## 🛠️ Technologies Used

- Python
- Hugging Face Transformers
- FLAN-T5
- Streamlit

## 🔄 How It Works

User enters a topic

↓

Prompt is created

↓

FLAN-T5 pretrained model

↓

Generated text

↓

Displayed through Streamlit
